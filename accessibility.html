Accessibility

Built for every visitor.

This site should work whether you use a screen reader, a keyboard, magnification or voice control, so you can see my work, compare pricing and start a project the same way anyone else can.

The standard

I build sianicreates.com to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. Every page runs through automated testing on phone and desktop sizes. I also check it by hand with a keyboard and a screen reader before changes go live.

What's built in

  • A skip link at the top of every page jumps straight to the main content.
  • Everything works with a keyboard, and the element you're on always shows a clear outline.
  • The option buttons on the Start a project form tell screen readers which choices are selected.
  • When a form field needs attention, the form says which one and what's missing.
  • The form announces which step you're on as you move through it.
  • Text and buttons meet AA color contrast.
  • If your device is set to reduce motion, the opening animation and other movement stop.
  • Every image of my work has a written description.

Still being worked on

  • The case studies show client sites as screenshots. Each one has a description, and a link opens the live site, but text inside a screenshot can't be read aloud or resized the way page text can.
  • Links to client sites, Google and other services take you to pages I don't control. I build my clients' sites to the same standard, but other services may not meet it.
  • Confirmation emails from the Start a project form haven't been tested with every email app and screen reader yet.
